# Guitar Exercises App

Pasta de contexto de um app de macOS para a prática diária de guitarra do Pedro.

- `PROMPT-INICIAL.md`: prompt para colar no Claude que vai desenvolver o app.
- `CLAUDE.md`: instruções que o Claude lê sozinho ao abrir esta pasta.
- `docs/01-roadmap.md`: roadmap de 6 meses.
- `docs/02-exercicios-videos.md`: vídeos de apoio da fase 1.
- `docs/03-gosto-musical-e-repertorio.md`: gosto musical e repertório por fase.
- `docs/04-requisitos-do-app.md`: features, telas, design, riscos e fases de desenvolvimento.
- `data/exercises.seed.json`: catálogo inicial de exercícios, em formato estruturado.
